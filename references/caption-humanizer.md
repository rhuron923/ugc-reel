# Caption humanizer

Two passes make short on-screen captions read like a friend texting, not like a brand or a chatbot. Pass 1 fixes words and phrasing. Pass 2 fixes the shape of the whole caption set (hook, build, product, payoff). Full humanizer guides cover paragraphs; for 2-7 word lowercase captions only the subset below can show up, so ignore everything else.
Examples use a made-up travel mug. Keep every fact, claim and number from the draft. Never add specifics that were not given.

## Pass 1: words and phrasing

1. **Em dash.** The single most flagged machine tell. Use a line break, a comma or a full stop instead of a dash. Do not swap in a colon.
   - bad: `it keeps coffee hot — all day`
   - fixed: `coffee still hot at 4pm`

2. **Negative parallelism ("not X but Y").** Negates one thing to set up another. Say the real claim directly.
   - bad: `not just a mug, it's a ritual`
   - fixed: `my coffee stays hot now`

3. **Rule of three.** Three tidy items to sound complete. Keep the one that matters, or two if the speaker would really say two.
   - bad: `hot, fresh, and portable`
   - fixed: `hot all morning`

4. **AI vocabulary.** Words like elevate, seamless, curated, game-changer, journey, unlock, delve, vibrant, crucial, ultimate. Use the word a person would text.
   - bad: `elevate your morning routine`
   - fixed: `my mornings got easier`

5. **Hype and promo adjectives.** Stunning, revolutionary, effortlessly, premium, must-have. Describe what the thing does instead.
   - bad: `the ultimate must-have mug`
   - fixed: `fits my cupholder, finally`

6. **Significance inflation.** Puffing a small thing into a big one ("a testament to", "changes everything", "a whole new era").
   - bad: `this mug changes everything`
   - fixed: `it fits my bag, that's it`

7. **Copula avoidance.** "Boasts", "features", "serves as" instead of is, has, does.
   - bad: `boasts a leakproof lid`
   - fixed: `the lid actually doesn't leak`

8. **Colon-label constructions.** "Pro tip:", "Reminder:", "The result:" read as a template. Just say the line.
   - bad: `pro tip: get the lid version`
   - fixed: `get the one with the lid`

9. **Emoji and symbol decoration.** Sparkle, fire or arrow emoji, hashtags and ✨ as punctuation. Captions are plain lowercase text unless told otherwise.
   - bad: `obsessed ✨☕ #musthave`
   - fixed: `obsessed with this mug`

10. **Scare quotes and curly quotes.** Quote marks around a normal word, or curly quotes in a caption.
    - bad: `my “perfect” morning mug`
    - fixed: `my morning mug`

11. **Stacked punctuation and signposting.** "!!!", "...", "Here's the thing:", "Let me explain", "Spoiler:".
    - bad: `so here's the thing... it works!!!`
    - fixed: `it works`

12. **Filler and hedging.** "Honestly kind of maybe", "it's important to note", "basically", used to pad word count.
    - bad: `it's honestly basically so good`
    - fixed: `so good`

## Pass 2: shape

Run these one at a time on the whole set, reading it as a skeleton (hook, build, product, payoff). Pick one or two interventions per variant. Do not apply all of them.

1. **Stated lesson / moral closer.** The last caption explains what the viewer should learn. Cut it, or end on the moment or the result.
   - bad: `cold coffee / bought this mug / now it's hot / lesson: invest in good gear`
   - fixed: `cold coffee again / bought this mug / still hot at 4pm`

2. **Tidy, fully resolved arc.** Problem, product, solved, every time. Break the line: end on the result mid-thought, open on the payoff and rewind, or leave one small thing unresolved.
   - bad: `my coffee went cold / then I found this / now it never does`
   - fixed: `still hot at 4pm / (it was cold by 10 last month)`

3. **Performed body emotion vs plain feeling.** Chest tightening, sinking stomachs, "my heart dropped". Name the feeling the way a person texts it.
   - bad: `my stomach dropped when it spilled`
   - fixed: `i was so annoyed when it spilled`
   - Keep a body detail only if the visuals need it and it is the one moment that earns it.

4. **Vague allusion vs concrete specific.** "Something I tried", "a certain mug", "recently". Name the real thing the draft already gives you (the product, the time, the number). If the draft gives no specific, do not invent one, just cut the vague line.
   - bad: `i tried something new lately`
   - fixed: `i switched to this mug in march`  (only if "march" was supplied)

5. **Reader acknowledgement.** Humans sometimes admit the viewer is there. One light touch at most, never in every variant.
   - bad: `this mug is great for everyone`
   - fixed: `ok you're gonna want this one`

6. **Shape convergence across variants.** If every variant opens with the same hook type, has the same beat order and ends the same way, that is the fingerprint. Compare variants and give each a different skeleton.
   - bad (three variants, same skeleton): all `you hate X / but now you Y`
   - fixed: variant A `you hate X / but now you Y`; variant B one static POV line only; variant C payoff first (`still hot at 4pm`) then `it was cold by 10 before`

## How to run it on a caption set

1. Read the set as written and note the hard caption rules you were given (word count, lowercase, number of captions, voice). Those always win over any pattern below.
2. Pass 1, line by line: check each caption against the 12 patterns and rewrite only lines that hit. Prefer plain words over a swap to another fancy word.
3. Pass 2, as a set: write the skeleton (hook, build, product, payoff), then audit the six shape items one at a time.
4. Choose one or two shape interventions per variant. Make them different between variants, and be able to say why each variant got its shape.
5. Keep every fact, claim and number. Never add a specific, name, price, date or result that was not in the draft. If a fix needs one you do not have, cut instead.
6. Re-check the hard caption rules after editing (still lowercase, still 2-7 words per line, still 1-4 captions, creator voice, no brand voice). Do not drift into a new default, such as every line ending in a question.
7. Read the set aloud once. If a friend would not text it, loosen it. Plain beats polished.
8. Show before → after for each changed line, grouped by variant, and say in a few words which pattern each change fixed.
